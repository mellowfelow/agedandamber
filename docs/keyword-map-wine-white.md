## 1. Phase 1 — Filter Summary

**Pinot Grigio — light noise.** Dropped recipe/cooking content (pinot grigio for risotto 1,000 · pinot grigio risotto 1,000 · pinot grigio sangria 590 · pinot grigio for cooking 1,000) and one pop-culture collision, "Bride Wars Pinot Grigio" (590 vol, a movie-tie-in reference, not a sellable SKU).

**Sauvignon Blanc — clean.** Dropped only the standalone "blanc" query (9,900 vol, KD 77) as too ambiguous/generic to be a usable target, and light recipe noise (cook with sauvignon blanc 1,600 · sauvignon blanc for cooking 1,000).
