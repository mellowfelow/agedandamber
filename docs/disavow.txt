#        (GSC's Links report had no data yet on 2026-09-09 — check again in ~2-4 weeks), OR
#      - Bing Webmaster Tools -> Backlinks -> Export.
#   2. For each referring domain in the export, add a line:  domain:<the-domain>
#   3. Keep the "domain:" prefix (disavows the whole domain, including subdomains and
#      future pages) — for a profile this toxic there is no reason to disavow
